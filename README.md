# 🎓 EduLearn - Modern AI-Powered Academic Assistant & Student Workspace

**EduLearn** is a comprehensive, modern student workspace built with **React 18+**, **TypeScript**, and **Tailwind CSS**. It combines AI study tools, developer studios, career prep coaches, and student productivity utilities into a unified web application.

---

## ✨ Features

- ** Academic Dashboard**: Overview with personalized greetings, study streak counter, stats, and upcoming deadlines.
- ** AI Study Tools**:
  - **Topic Explainer**: ELI5, Intermediate, and Advanced depth levels with visual analogy cards and interactive mini quizzes.
  - **Quiz & Practice Generator**: MCQ tests with step-by-step scoring analytics and celebration confetti.
  - **Summarizer**: Condenses articles/transcripts into bullet points, TL;DR summaries, interactive flip flashcards, and mind maps.
- ** Developer & Coding Studio**:
  - **Code Generator & Converter**: Multi-language translation with side-by-side diffs and runnable sandbox simulator.
  - **Code Debugger**: Diagnoses root causes, categorizes bugs, and provides step-by-step solution code with health scores.
  - **App & Prototype Builder**: Multi-file code generator with an interactive live preview sandbox container.
- ** Career & Project Prep**:
  - **Interview Prep Coach**: Simulated technical/behavioral interview practice with score cards and benchmark answers.
  - **Project Planner**: 4-sprint milestone roadmap generator with deliverables checklists.
- ** Productivity & Utilities**:
  - **Attendance Tracker**: Visual SVG radial progress rings with Bunk Calculator formulas.
  - **Class Notes Hub**: Markdown-supported note taking with tag filters and search.
  - **Task Manager**: Kanban board & list view with urgency badges.

## 🛠️ Local Development Setup

```bash
# Clone the repository
git clone https://github.com/BojapallyNaveena/IQOO-Hackathon.git
cd IQOO-Hackathon

# Install dependencies
npm install

# Start the dev server
npm run dev
```

## 🚀 Vercel Deployment

This project is pre-configured for seamless deployment on **Vercel**:

1. Push your code to GitHub (already configured with `vercel.json`).
2. Go to [Vercel](https://vercel.com/new) and click **Add New Project**.
3. Import your repository: `BojapallyNaveena/IQOO-Hackathon`.
4. Vercel automatically detects the Vite configuration:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**.
